# RAGDiag Examples

This directory will contain end-to-end runnable examples illustrating how to wrap different RAG frameworks and custom architectures using the `ragdiag.Pipeline` adapter interface.

## Planned Examples

- **Custom Python RAG Adapter**: Wrapping an in-memory or BM25/vector search pipeline.
- **LangChain / LlamaIndex Adapters**: Integrating popular orchestration frameworks into RAGDiag evaluation.
- **Multi-Pipeline Comparison**: Evaluating and diagnosing two pipeline configurations side-by-side.

*Examples will be added in subsequent implementation phases alongside the evaluation and diagnosis engines.*
